## 初版提示词

Use case: infographic-diagram. Create one complete 16:9 Chinese presentation slide image titled「系统整体流程」for the project「绿茵视界」, a 2022 World Cup database and fan community platform. Match the established slide style: crisp white background, deep navy typography, emerald football-pitch green, vivid lime accents, elegant corner swooshes and a subtle stadium atmosphere. Make it look like a polished classroom project presentation, not a UI screenshot. The diagram must be the main focus, with large Chinese labels and clear directional arrows. Use a clean left-to-right flow with the data source at left, one central MySQL database cylinder, and three clearly separated user/service branches at right. Include tasteful illustrative pictograms for source documents, validation checklist, database, match ball, fan discussion, and admin shield; these illustrations should support the flow without crowding it. Exact data pipeline:「公开数据」→「解析校验」→「导入预览」→「事务导入」→「MySQL 20 表」. From the central database, show three labeled branches: branch 1「访客」→「赛事查询」→「比赛、球队、球员」→「积分榜、射手榜、动态图表」; branch 2「登录用户」→「球队与比赛收藏」→「话题与评论」; branch 3「管理员」→「赛事数据维护」→「社区审核」→「通知与日志」. Indicate that administrator maintenance writes back to the central database with a clear return arrow. Use exactly these labels; do not invent extra features, match scores, dates, statistics, fictional teams or extra text. Maintain enough white space and high contrast for classroom projection. Do not make the text tiny; if needed, shorten only line breaks, never change wording. No watermark.
