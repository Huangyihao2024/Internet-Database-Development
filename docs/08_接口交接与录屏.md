# 公共模块交接与录屏

## 已提供接口

- GET /index.php/site/me：authenticated；登录后id、username、role。写操作仍从Yii会话取用户，不信任客户端身份。
- common/controllers/AdminController：管理员访问限制、POST删除约束，后台写操作记录AuditLog。
- AuditLog::record(action, objectType, objectId)：记录当前操作者及对象，不存请求正文。
- NotificationService::notifyUser(userId, subject, content)：写wc_sys_notification并投递邮件；默认文件投递，返回布尔结果。SMTP配置仅放本机params-local/main-local，allowExternalEmail默认false。
- MatchReference：社区关联比赛的只读查询。赛事模块写wc_data_match和wc_data_team后，发帖下拉选项自动出现。比赛详情入口由王乐之完成后统一加入导航。
- FanPost/FanComment：社区数据；status为pending/published/rejected/archived；回复parent_id必须引用同一话题的公开评论。
- yii worldcup-setup/sync-downloads：登记data/team、data/personal现有PDF/ZIP/PPTX/MP4及摘要。实际SQL可用worldcup-setup/export-schema导出。
