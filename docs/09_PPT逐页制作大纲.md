# 绿茵视界：PPT逐页制作大纲

## 制作目标

22页，五个部分；录屏目标14分05秒。PPT讲解约11分50秒，穿插网页操作约2分15秒。网页操作直接嵌入相应功能页，演示后返回同一页继续讲解。给转场、网络和人工操作预留55秒，最终视频保持5—15分钟。

本文件是制作说明；各页“可直接放入PPT的文字”可复制上屏，布局、素材、操作和讲解提示写入演讲备注。逐字讲稿见[10_录屏逐字讲稿.md](10_录屏逐字讲稿.md)。

依据：作业汇总PPT第5—12页；完整版L5-L8课件第32页项目展示、第33页录屏讲解。展示应覆盖两人对表、具体代码和文档的分工，以及部署、业务网页和PPT讲解。

## 整体结构

|部分|页码|要回答的问题|
|---|---|---|
|一 项目与分工|P01—P04|做什么、给谁用、谁负责什么|
|二 架构与数据|P05—P08|Yii2怎样组织，表和数据怎样关联|
|三 功能与实现|P09—P17|怎样部署，前后台怎样完成业务|
|四 验证与协作|P18—P19|怎样检查、怎样分工协同|
|五 页面与成果|P20—P22|业务页面是否讲全，交付怎样组织|

## 全局版式

- 画布16:9，建议1920×1080；安全边距左右0.6英寸，上下0.4英寸。
- 主色深海军蓝`#102838`，辅助球场绿`#168765`，少量亮绿`#B6EE67`强调；正文用深色，背景以白色为主。网站截图保持原色。
- 字体统一微软雅黑或思源黑体；标题38—42pt，正文24—28pt，表格22—24pt，代码20—22pt，素材来源16—18pt。关键数字52—64pt。
- 一页一个结论；一般正文3—5条，每条8—18个汉字。分工表、代码页允许适度增加信息，但先删冗余文字，再调整布局。
- 截图占页面55%—75%；保留关键操作和结果，裁去桌面、空白边缘、口令及无关窗口。手机截图截取一屏关键内容。网页图缩放后，关键标签不足20pt时改为单图裁剪放大或分步呈现。
- 图、表、文字按同一基线对齐；正文与图中说明靠近。流程与关系图使用可编辑图形，完整ER图留在设计文档。
- 页脚只放页码；章节名可以在页眉小号出现。封面不放日期、班级。校徽使用原色。
- 动画以“出现／淡入”为主，0.2—0.4秒；页面回顾用逐屏替换。正文不要整段飞入，不使用自动循环动画。
- 代码与数据口径在制作前对照当前仓库。具体业务收尾、素材负责人和任务状态见任务清单。
