# 真实截图与插入

统一保存到仓库根目录figures。页面、Git提交记录、主要代码和目录截图均保存在该目录。

Tower需要本人登录：登录tower.im，创建知行学习团队项目，邀请另一位成员，按任务CSV建立任务并分配负责人；至少移动一张实际任务卡。按Win+Shift+S框选项目名、任务、负责人、状态，隐藏邮箱及其他项目，保存figures/tower_tasks.png。

GitHub截图：打开仓库，进入Commits，展示提交标题、作者、日期及短哈希，框选主内容保存figures/github_commits.png。

TeX插图：在实现文档对应段落使用includegraphics[width=linewidth]{../../figures/tower_tasks.png}，再XeLaTeX编译两次。正式源码中应写反斜杠命令，例如\includegraphics[width=\linewidth]{../../figures/tower_tasks.png}。图片保留原色；文件名与引用保持一致。
