# 数据来源与导入

首个数据届次：2022年卡塔尔世界杯。官方核对：https://www.fifa.com/en/tournaments/mens/worldcup/qatar2022 及其Results、Standings、Teams栏目。
比赛文本初始来源：https://github.com/openfootball/worldcup/blob/master/2022--qatar/cup.txt ，仓库声明CC0-1.0。原始文件和许可下载在data/raw，下载记录保存URL和SHA256。
数据阶段：先解析届次/阶段/小组/日期/对阵/比分/球场与比赛事件，生成预览并核对官方记录，再导入20表。球员与阵容来自独立名单数据，与比赛事件按姓名和球队关联。
统计数据由本地数据库聚合，页面日常不依赖付费API或实时抓取。保存来源、导入时间及source_key，重复导入只更新同一记录。比赛时区与北京时间显示分开保存和转换。
