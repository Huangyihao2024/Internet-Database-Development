# 邮件服务

默认使用本机文件投递，不发外部邮件。审核通知已通过NotificationService::notify接入；报名和资源评论由王乐之调用同一接口。后台runtime/mail保存EML，仅管理员能查看记录。

若以后获得实际发信授权，可在被忽略的common/config/main-local.php为mailer配置Symfony transport的host、port、username、password、scheme，并在params-local.php设置allowExternalEmail=true。SMTP口令只在本机配置，不上传Git、不放截图。未授权时保持false。接入前需按实际服务商配置sender域名和TLS，不关闭证书验证。
