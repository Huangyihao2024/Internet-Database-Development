# 公共模块交接

黄奕浩已完成：登录注册、前台会话身份接口、团队与成员展示、本人资料编辑、后台团队/成员编辑、公告增删改与状态发布、作业下载。对应Model、Controller、View与接口均在app中。

## 对其他模块的约定

- 普通注册用户为member，管理员为admin，user.status=10表示可登录。
- 服务器获取用户：Yii::$app->user->id；身份：Yii::$app->user->identity；管理员检查：identity->isAdmin。
- 前台身份接口：GET index.php?r=site/me。访客返回authenticated=false，登录后返回id、username、role。
- 后台新增Controller建议继承common/controllers/AdminController；整个后台已有管理员访问控制。
- 前台写操作需在Controller要求登录并检查资源所有权；Yii默认CSRF保持启用，删除、收藏等动作明确限定POST。
- 表单优先使用ActiveForm，输出通过Html::encode。导航只添加已实现的入口。
- 下载材料放data/team或data/personal，运行yii team-setup/sync-downloads登记；链接只接收记录ID。
- 不运行Yii默认user建表迁移；当前15表由data/install.sql创建。后续结构变更先协调。
