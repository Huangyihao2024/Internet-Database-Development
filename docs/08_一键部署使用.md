# 一键部署（加分功能）

Windows预先安装PHP 8.3、MySQL 8、Python后，双击根目录“一键部署.cmd”。无需手动创建数据库、填写数据库口令或初始化账号。脚本自动创建独立数据目录、实例、专用库及用户，生成随机口令、安装锁定依赖、初始化配置、导入15张表和示例数据，然后启动并检查前后台。

本机已实际运行，端口：数据库13318、前台8775、后台8776。独立数据在.local/oneclick，账号在.local/oneclick/release/.local/accounts.json，均不提交Git。中文路径通过D盘目录联接兼容MySQL。不会停止或覆盖已有MySQL80和原开发实例。

重复运行保留数据库及本机配置，更新源码和下载登记并检查页面；端口冲突或未完成的初始化会停止并提示，不擅自覆盖数据。换电脑可设置ZHIXING_PHP_ROOT、ZHIXING_MYSQL_ROOT。首次需网络下载依赖，已安装依赖可复用；不关闭TLS，不跳过平台检查。该部署目标是Windows本机演示，不等同于自动安装所有系统软件或公网生产部署。

运行日志在.local/oneclick，故障先查看日志。部署结束后检查前后台页面。录屏时应从一次全新独立部署开始，展示建库、初始化、页面与账号登录，隐藏口令。
