# 展示统稿与组长讲解

## 展示结构

1. 项目目标：团队介绍、学习资源、活动交流与课程成果汇集。
2. 两人分工：本人负责公共、留言、部署与完整录屏；王乐之负责资源、活动、评论、图表与PPT统稿。列明本人7张表及王乐之8张表、MVC文件与文档。
3. 技术结构：Yii2 Advanced、MySQL、前后台分离部署、15张表。
4. 组长模块：展示首页、成员页、管理员编辑资料、公告发布、作业下载与拒绝越权。
5. 王乐之模块：待本人提供实际资源、图表页面后补充。
6. 王乐之模块：待本人提供实际报名、审核页面后补充。
7. 协作：展示真实Git与Tower记录；目前远程仓库创建、Tower仍需各人登录加入。
8. 部署：新库导入结构、初始化样例、前后台启动、下载成果。

## 组长讲解词

我们选择校园学习团队门户作为主题，把成员介绍、内容发布与课程成果下载集中在一个网站中。我负责公共登录与权限、团队和个人展示、公告以及部署。成员资料由同一张表驱动，后台修改后前台能直接读取更新。普通账户只允许维护自己的资料，后台必须使用管理员身份。公告草稿不会公开，发布后才出现在首页。下载中心先验证文件范围与SHA256，再返回实际文件，避免任意路径读取。代码按Yii2的Model、Controller、View组织，每个人都承担一组完整MVC模块。
