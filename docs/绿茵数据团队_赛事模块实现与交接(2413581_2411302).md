## 本次实现

1. `scripts/build_worldcup_data.py` 解析 OpenFootball 原文，并与同源 `worldcup-full.json` 核对64场比分和事件。四场原文省略的同日开赛时间在预览中保留警告；使用同日上一场的时间。
2. `app/console/controllers/WorldcupImportController.php` 实现源数据校验、预览和事务导入，按届次、球队代码、阵容组合及比赛/事件来源键去重；导入失败回滚。
3. `app/common/models/` 新增11个赛事及收藏 ActiveRecord，提供关联和 Rules。初始字段由仓库脚本生成，再适配业务关系。当前并未真实运行 Gii，不能以此作为 Gii 截图证据。
4. 前台6个控制器覆盖比赛、球队、球员、积分、统计图表及收藏；后台赛事维护按九类表提供新增、编辑、删除，管理员身份由公共 `AdminController` 检查，写表单由 Yii CSRF 保护。
5. 四类图表由 `WorldcupStatistics` 实时读取数据库，JavaScript 在届次、阶段和球队改变时重新请求 JSON；有空数据和请求失败提示。颜色采用原有深海军蓝、球场绿主题。
6. 比赛页面将 UTC 开赛时间转换为北京时间显示；日期筛选也以北京时间解释。

## 核心统计规则

- 小组赛使用90分钟比分计算胜3、平1、负0，排序先看积分、净胜球、进球数。若全部相同，需进一步按相互赛果及公平竞赛分判定；现有代码未实现这一极端平分规则。
- 正式进球数含常规时间和加时赛，点球大战单独记录并排除。
- 射手榜只计 `goal` 和 `penalty_goal`，排除乌龙球、点球大战。

## 运行命令

在已按原部署文档配置 PHP 8.3、MySQL 8 与 Composer 依赖后：

```text
python scripts/build_worldcup_data.py
python scripts/check_worldcup_data.py
cd app
php yii worldcup-import/preview
php yii worldcup-import/run
php yii worldcup-import/run
```
