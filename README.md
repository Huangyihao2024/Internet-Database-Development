# 绿茵视界：世界杯赛事数据与球迷互动平台

开发团队：绿茵数据团队。组长：黄奕浩（2413581）；组员：王乐之（2411302）。
以2022年世界杯作为首个完整数据届次，保留多届赛事扩展。前台提供赛事、球队、球员、积分榜、射手榜、收藏、球迷讨论与数据图表，后台管理赛事数据和社区内容。

当前完成选题、需求、20表结构草案、两人任务和Yii2原始框架准备。世界杯业务代码、数据入库和页面尚未实现；校园项目的完成状态不沿用。

- docs/01_选题与需求.md：功能与页面。
- docs/02_两人分工.md、docs/个人分工：全部任务归属。
- docs/03_数据库与接口.md：20张表及统计口径。
- docs/04_课件要求与加分清单.md：必做、选做、建议与加分项。
- docs/05_数据来源与导入.md：官方核对及数据来源。
- data/install.sql：新项目结构草案，尚未导入。
- data/personal：保留原个人报告；桌面三个个人实验文件夹保持原样。
- figures：后续页面、Git、目录和任务截图。

旧校园项目保存在Git分支reference/campus-theme及本机参考归档，供参考。新项目使用独立数据库和运行目录，不连接旧校园数据库。技术路线继续使用Yii2 Advanced、PHP 8.3及MySQL 8，环境软件可复用，网站内容及业务重新设计。
